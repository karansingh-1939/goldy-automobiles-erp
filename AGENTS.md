# GOLDY AUTOMOBILE ERP

This project is an offline-first Windows desktop ERP for an automobile repair workshop.

Technology Stack:

Frontend:

- React
- Tailwind CSS
- React Router
- TanStack Table
- Chart.js

Backend:

- Node.js
- Express.js

Desktop:

- Electron

Database:

- SQLite

Requirements:

- Offline first
- Single laptop operation
- Production quality architecture
- Modular code structure
- Windows EXE packaging

Core Modules:

1. Authentication
2. Customer Management
3. Vehicle Management
4. Job Cards
5. Inventory Management
6. Multi-Godown Warehouses
7. Purchasing
8. Billing
9. GST Reporting
10. Profit & Loss
11. Expenses
12. Tally Export
13. Dashboard & Analytics

Inventory Requirements:

Store:

- SKU
- Item Name
- Purchase Cost
- Selling Price
- Quantity
- Batch Number
- Warehouse
- Supplier
- Minimum Stock

Financial Requirements:

Every invoice must calculate:

Revenue
Cost
Gross Profit
Net Profit

Profit = Selling Price - Purchase Cost

Support expense tracking:

- Rent
- Salary
- Electricity
- Internet
- Miscellaneous

Architecture Requirements:

- Repository pattern
- Service layer
- REST API
- Role-based access control
- SQLite database

The code should prioritize maintainability and future expansion.
