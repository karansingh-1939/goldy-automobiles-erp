Export Invoices to Tally

Tally XML Import Guide

This export generates a standard Tally XML format containing Sales Vouchers. To import this file into Tally ERP 9 or TallyPrime, follow these steps:

  • Ensure the ledgers Sales Account, CGST Ledger, SGST Ledger, and IGST Ledger exist in your Tally company or are configured to match.
  • In Tally, go to Import of Data > Vouchers.
  • Select the downloaded XML file and specify the file path.
  • Tally will import all invoices as Sales Vouchers with appropriate debit/credit allocations.
